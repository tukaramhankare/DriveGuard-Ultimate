What it actually does

Full-drive scan

Copy an entire drive or removable device, then hash every file with SHA-256 to catalog duplicates and corruption in one pass.

Locate the original

Right-click or long-press any file to jump straight to its source location — rename, copy, or replace it there, verified by a matching hash before anything is overwritten.

Delete with a safety net

Delete a single file or a whole selection. DriveGuard always shows the selected count and asks for confirmation before anything is removed.

Back up before you touch anything

Copy a single file or a full selection to a folder you choose — a safeguard you can take before any rename, replace, or delete.

A log you control

Every action is recorded in an Operation Log you can review — and clear yourself, on your own terms, without touching a single real file.

How a scan reads

Every check DriveGuard runs lands as a line in the Operation Log. Nothing happens silently.
